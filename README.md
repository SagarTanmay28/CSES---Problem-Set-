## How to Use This

- **Filter by tag** — use your editor's search (Ctrl/Cmd+F) on a technique name (e.g. "Segment Tree", "DSU", "Binary Lifting") to pull every problem that uses it across sections.
- **Filter by difficulty** — search for 🟢, 🟡, or 🔴 to build a study queue at your current level.
- **Suggested order** — within each section, problems are listed roughly in CSES's own order, which is already difficulty-progressive; solving top-to-bottom per section works well.
- **Recommended path for beginners** — Introductory → Sorting and Searching → Dynamic Programming → Graph Algorithms, then branch into Range Queries / Tree Algorithms / Mathematics / String Algorithms / Geometry, and finish with Advanced Techniques + Additional Problems.
